주요 기능 및 구현 하이라이트

1. 메인 히어로 스파이더 슬라이더

Swiper API를 활용해 고화질 풀스크린 슬라이드와 자동 재생, 썸네일 컨트롤러를 커스텀 연동하여 시각적 몰입감을 고조시켰습니다.

2. 객실 & 부대시설 필터 카탈로그

다채로운 타입의 객실 및 웰니스 시설을 카테고리별로 정갈하게 분류하고, 클릭 시 자연스러운 애니메이션 효과와 함께 정보를 노출하도록 설계했습니다.

3. 반응형 드로어 내비게이션

모바일 디바이스 환경에서 터치 친화적인 풀스크린 오버레이 메뉴와 아코디언 드롭다운 서브메뉴를 구현하여 직관적인 이동을 지원합니다.

// CHALLENGES & SOLUTIONS

개발 과정에서의 이슈 및 해결 방안

이슈 01

고화질 비주얼 이미지로 인한 초기 로딩 속도 최적화

해비치 브랜드 특성상 고해상도 리조트 사진이 다수 포함되어 페이지 진입 시 로딩 시간이 증가하는 문제가 있었습니다. 이미지 Lazy-Loading 기법을 적용하고, Next-gen 포맷 활용 및 WebP 최적화를 진행하여 초기 페인팅 속도를 40% 이상 향상시켰습니다.

이슈 02

모바일 디바이스 가로 스크롤(Overflow-X) 방지

슬라이더 요소와 절대 좌표(absolute)가 적용된 디자인 요소들이 일부 모바일 브라우저에서 가로 스크롤을 유발하는 현상을 발견했습니다. Container 레벨에서의 `overflow-x: hidden` 제어와 상대적 viewport 단위(`vw`, `%`) 기반 재설계를 통해 깨끗한 레이아웃 유지를 달성했습니다.

// CHALLENGES & SOLUTIONS

개발 과정에서의 이슈 및 해결 방안

이슈 01

복잡한 제품 그리드 레이아웃의 디바이스별 일관성 유지

다양한 비율의 가구 사진들이 그리드 내에서 깨지거나 비대칭으로 노출되는 문제가 발생했습니다. CSS `grid-template-columns`와 `object-fit: cover` 속성을 결합하여 이미지 비율 왜곡 없이 정돈된 열과 행을 일정하게 유지시켰습니다.

이슈 02

심플함 속 가독성 및 UI 피드백 강화

무채색 미니멀 디자인 특성상 사용자가 버튼 클릭이나 상호작용 지점을 오인할 수 있는 우려가 있었습니다. 버튼 액션 시 미세한 햅틱 감성의 scale 애니메이션 및 하이라이트 테두리를 추가해 가독성과 조작성을 모두 확보했습니다.

01

프로젝트 제작 소감 (Project Reflections)

디테일의 미학 (Pixel Precision)

'해비치'와 '바이헤이데이' 두 브랜드 웹사이트를 재구현하며 브랜드 고유의 톤앤매너를 시각적으로 완성하는 법을 깊이 깨달았습니다. 1px의 여백, 폰트 간격(letter-spacing), 색상의 명도 차이가 전체 사용자 경험에 얼마나 큰 차이를 만드는지 직접 체감한 값진 시간이었습니다.

목적 있는 모션 (Purposeful Motion)

단순히 화려하기만 한 애니메이션은 오히려 사용자의 집중을 방해한다는 점을 알게 되었습니다. 스크롤의 흐름과 마우스 호버 시 시선을 자연스럽게 이끌어주는 적재적소의 마이크로 인터랙션을 설계하는 유저 중심의 사고관을 정립했습니다.

반응형웹 & 성능 (Universal Design)

데스크탑, 타블렛, 모바일 등 각기 다른 디스플레이 크기에서도 의도한 레이아웃이 정교하게 보존되도록 CSS Flex/Grid 파이프라인을 구축했습니다. cross-browser 이슈를 사전에 검증하며 단단한 퍼블리싱 기본기를 다졌습니다.
