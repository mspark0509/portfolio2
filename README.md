# 포트폴리오 사이트 — 전수 감사 및 성능 최적화 수정본

기존 정적 HTML/CSS/JavaScript 구조와 시각 디자인을 유지하면서, 반복 렌더링·행성 전환·리소스 준비 과정에서 불필요한 작업을 줄인 수정본입니다.

## 포함 파일
- `index.html`, `projects.html`, `resume.html`, `contact.html`: 기존 4개 페이지
- 각 페이지의 CSS/JS 파일과 공통 `planets.js`, `stars.js`
- `AUDIT_REPORT.md`: 파일 분류, 변경 내역, 무결성 및 검증 결과
- `PERFORMANCE_REPORT.md`: 코드에서 확인된 병목, 수정 사항, 미측정 항목

## 실행 및 배포
1. ZIP을 별도 폴더에 압축 해제합니다.
2. 기존 GitHub 저장소의 파일을 백업합니다.
3. 수정본의 HTML/CSS/JS 파일을 기존 저장소에 반영합니다.
4. **기존 저장소에 `images/planets/`가 있다면 반드시 보존**합니다. 원본 ZIP에는 이 폴더가 포함되지 않았지만 `planets.js`가 `jupiter-n.webp`, `jupiter.webp` 등 행성 이미지 파일을 참조합니다.
5. GitHub에 커밋/푸시한 뒤 GitHub Pages 배포 완료를 기다립니다.
6. 네 페이지를 각각 직접 열어 메뉴 이동, 행성 전환, 섹션 휠, 프로젝트 탭/미리보기, 문의 폼, 모바일 메뉴를 확인합니다.

## 최신 2차 휠/별 성능 수정
- 휠 이벤트마다 반복하던 섹션 위치 DOM 측정을 캐시 기반으로 변경했습니다.
- 데스크톱 커스텀 휠 이동이 활성화된 경우에만 `passive:false` 리스너를 등록합니다.
- 휠 이동 시간을 240–340ms로 조정하고 입력 잠금 해제 대기를 줄였습니다.
- 화면에 보이는 별 밀도를 약 300개 낮추고, 별 캔버스만 최대 60fps로 제한했습니다.
- 세부 사항과 검증 한계는 `PERFORMANCE_REPORT.md`를 확인하세요.

## 검증 상태
- JavaScript 구문 검사: 통과
- HTML의 중복 ID 및 로컬 CSS/JS 참조 검사: 통과
- CSS 중괄호 균형 검사: 통과
- 브라우저에서의 실제 동작/FPS/메모리/Lighthouse: 이 실행 환경에서 Chromium이 제한 시간 안에 페이지를 렌더링하지 못해 미검증입니다. 실제 성능 수치나 완전한 렉 해결을 주장하지 않습니다.

자세한 사항은 두 보고서를 참고하세요.
