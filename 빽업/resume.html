프로젝트 소감 및 자기소개서

두 프로젝트를 직접 기획, 퍼블리싱, 구현하면서 경험한 기술적 성장 소감과 프론트엔드 개발자로서의 가치관을 담은 자기소개서입니다.

01

프로젝트 제작 소감 (Project Reflections)

디테일의 미학 (Pixel Precision)

'해비치'와 '바이헤이데이' 두 브랜드 웹사이트를 재구현하며 브랜드 고유의 톤앤매너를 시각적으로 완성하는 법을 깊이 깨달았습니다. 1px의 여백, 폰트 간격(letter-spacing), 색상의 명도 차이가 전체 사용자 경험에 얼마나 큰 차이를 만드는지 직접 체감한 값진 시간이었습니다.

목적 있는 모션 (Purposeful Motion)

단순히 화려하기만 한 애니메이션은 오히려 사용자의 집중을 방해한다는 점을 알게 되었습니다. 스크롤의 흐름과 마우스 호버 시 시선을 자연스럽게 이끌어주는 적재적소의 마이크로 인터랙션을 설계하는 유저 중심의 사고관을 정립했습니다.

반응형웹 & 성능 (Universal Design)

데스크탑, 타블렛, 모바일 등 각기 다른 디스플레이 크기에서도 의도한 레이아웃이 정교하게 보존되도록 CSS Flex/Grid 파이프라인을 구축했습니다. cross-browser 이슈를 사전에 검증하며 단단한 퍼블리싱 기본기를 다졌습니다.

// 01. MOTIVATION & ESSENCE

"탄탄한 기본기와 감각적인 비주얼을 이어주는 프론트엔드 개발자"

프론트엔드 개발은 사용자가 가장 먼저 마주하는 웹의 첫인상입니다. 잘 짜인 화면은 단순한 데이터 표시를 넘어 브랜딩의 가치를 격상시킨다고 믿습니다.

저는 웹 표준과 웹 접근성을 준수하는 시맨틱 마크업을 바탕으로, 사용자 관점에서의 직관적이고 아름다운 UI/UX를 구현하는 데 깊은 보람을 느낍니다. 해비치 리조트 프로젝트와 바이헤이데이 퍼니처 프로젝트는 이처럼 섬세한 디자인 감수성과 기술적 완성도를 결합하고자 했던 대표적인 결실입니다.

// 02. PROBLEM SOLVING & VALUE

집요한 디테일과 문제 해결을 향한 열정

개발 과정에서 예기치 않은 디스플레이 왜곡이나 모바일 터치 이벤트 오류가 발생했을 때, 임시방편의 해결책에 그치지 않고 문제의 근본 원인(Root Cause)을 CSS 스펙과 DOM 라이프사이클 관점에서 파악하려고 노력합니다.

디자이너의 정교한 의도를 코드로 완벽하게 이식하는 높은 이해도를 가지고 있으며, 기획자 및 팀원과의 원활한 소통을 통해 서비스의 품질을 꾸준히 고도화할 준비가 되어 있습니다.

// 03. FUTURE VISION & ASPIRATION

지속적으로 진화하는 개발자로서의 비전

변화가 빠른 프론트엔드 생태계 속에서 모던 JavaScript 기술 모듈과 성능 최적화 방법론을 지속해서 습득하고 있습니다. 앞으로도 사용자가 매일 마주하고 싶어 하는 매력적이고 유연한 디지털 플랫폼을 만드는 프론트엔드 엔지니어로서 지속 가능한 성장을 이어갈 것입니다.
